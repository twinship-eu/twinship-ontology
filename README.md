# TwinShip Ontology Repository

Welcome to the TwinShip Ontology repository! This project provides a modular, extensible ontology for the TwinShip project, supporting semantic interoperability, data integration, and knowledge representation in the maritime domain.

## Repository Structure

- `model/` — Main ontology files (core, vocabularies, individuals, external imports)
- `docs/` — Documentation, diagrams, and usage examples
- `tools/` — Scripts and tools for ontology validation and management
- `tests/` — SHACL shapes, SPARQL queries, and other validation resources
- `examples/` — Example data and usage scenarios

## Getting Started

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/twinship-eu/twinship-ontology.git
cd twinship-ontology

# 2. Install uv (fast Python package manager)
curl -LsSf https://astral.sh/uv/install.sh | sh
# Or: brew install uv

# 3. Install dependencies
uv sync

# 4. Generate complete website (documentation + visualization)
./scripts/generate_website.sh

# 5. View the result
open docs/website/index.html
```

### Explore the Ontology

- **Foundation**: [model/twinship-base.ttl](model/twinship-base.ttl) - Base classes and properties
- **Modules**: [model/modules/](model/modules/) - Domain-specific modules (engine, hull, etc.)
- **Complete Ontology**: [model/twinship-core.ttl](model/twinship-core.ttl) - Aggregate importing everything

**Note**: The ontology uses OWL restrictions rather than rdfs:domain assertions to avoid unwanted inferences. For visualization, a domain/range version is automatically generated by the build scripts.

### Generate Documentation & Visualization

Generate complete website with WIDOCO documentation and WebVOWL visualization:

```bash
# Generate everything (documentation + visualization + landing page)
./scripts/generate_website.sh

# Start local web server
cd docs/website && python3 -m http.server 8000

# Open in browser
open http://localhost:8000
```

The landing page provides links to:
- **WIDOCO Documentation** - Comprehensive HTML documentation with diagrams and cross-references
- **WebVOWL Visualization** - Interactive force-directed graph visualization

**What gets generated:**
- `build/twinship-core-complete.ttl` - All modules merged
- `build/twinship-core-complete-viz.ttl` - Visualization-friendly version (domain/range)
- `build/twinship-core-complete-docs-viz.ttl` - Documentation version
- `docs/website/documentation/` - WIDOCO-generated HTML documentation
- `docs/website/visualization/` - WebVOWL interactive visualization
- `docs/website/index.html` - Landing page
