# Contributing to TwinShip Ontology

Thank you for your interest in contributing to the TwinShip Ontology! We welcome contributions from the community to improve and extend the ontology.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Make your changes** in a modular and well-documented manner.
3. **Validate your changes** using the scripts in `tools/` and tests in `tests/`.
4. **Submit a pull request** with a clear description of your changes and the motivation behind them.

## Guidelines

- Follow the modular structure for ontology files (core, vocabularies, individuals, external).
- Use clear, descriptive commit messages.
- Add or update documentation in `docs/` as needed.
- Ensure all new or modified ontology files are valid RDF/Turtle.
- Add or update SHACL shapes or SPARQL tests in `tests/` if relevant.

## Code of Conduct

Please be respectful and constructive in all interactions. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) if available.

## Questions?

Open an issue or contact the maintainers for help.
