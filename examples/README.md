# examples/

Public, synthetic (non-proprietary) instance data for the TwinShip ontology.

This is the opposite of [`data/`](../data/README.md): everything here is tracked
and committed normally. Use this folder for fictional/synthetic Knowledge Graph
(KG) individuals that are safe to publish alongside the ontology — e.g.
demonstrator vessels, sample component graphs, or data used in documentation
and papers.

Do not place real or proprietary vessel data here — that belongs in the
gitignored `data/` folder instead.

## Structure

One `.ttl` file per example dataset, named `<example-name>.ttl`, documented in
its own section below.

## Datasets

### `futuristic-vessel.ttl`

Synthetic component graph for the futuristic (diesel-electric) RoRo vessel
demonstrator: gensets, electric motors, CPP, ammonia fuel cells, ESS, and
related components, linked via `ido:connectedTo`/`ido:partOf`.

- **Source**: generated from a synthetic spreadsheet (`RoRo Futuristic Vessel
  KG Working File.xlsx`) matching the component structure used by
  `twinship-data-pipeline`'s futuristic-vessel extraction, plus a synthetic
  Rotterdam-Immingham time series (`RoRo Futuristic Vessel Voyages.dat`:
  positions, speed, wind and waves every 3 h) mapped to `Voyage`, `VoyageLeg`,
  `WayPoint` and weather individuals.
- **Generated by**: the stopgap generator `twinship-futuristic-vessel` (now
  archived). The input files and their conversion have moved to
  [`twinship-data-pipeline`](https://github.com/twinship-eu/twinship-data-pipeline)
  (input files in `data/`, described in `docs/futuristic-vessel.md`); exporting
  this example from the pipeline is planned.
- **Scope/limitations**: component/mechanical specs and one simulated voyage
  series (timestamps are `Estimated`, not logged operation). Propeller/shaft
  power, fuel and emission rates, draft and trim are not mapped (no matching
  ontology property), nor are VesselSpeedBin or SpeedReference individuals.
  Hand-authored placeholder individuals for EngineMode (per genset),
  EngineSpeedBin, DraftMode and TrimMode come from the pipeline's
  `RoRo Futuristic Vessel Operational Modes.ttl`; all their numeric values are
  zero placeholders pending the statistical model output, so treat them as
  structure demonstration only.
