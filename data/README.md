# data/

This folder contains **vessel-specific Knowledge Graph (KG) instance data** — OWL individuals populated with real or proprietary vessel data.

These files are **gitignored** and will never be committed or pushed to GitHub, as they may contain commercially sensitive or confidential vessel information.

## What belongs here

- `.ttl` files with OWL individuals for specific vessels (e.g. RO-RO ferries, tankers)
- Instance data generated from AIS feeds, technical specifications, or operational records
- Experimental populations of the TwinShip ontology for testing and validation

## What is tracked

- `README.md` — this file only

All other files in this folder are gitignored and will never be committed.

## IMO alignment working artifacts

The following files are generated by the IMO alignment scripts and live here as transient working artifacts:

| File | Generated by | Purpose |
|---|---|---|
| `IMO_Compendium.xlsx` | `extract_imo_compendium.py` | Cached Excel download — delete to force re-download |
| `imo_alignment_review.csv` | `align_imo.py --prepare` | Ranked candidates for review; edit `action` column then run `--apply` |
| `imo_compendium_filtered.csv` | `extract_imo_compendium.py --keywords` | Keyword-filtered subset of the compendium |
| `imo_candidates.csv` | `extract_imo_compendium.py --match-ttl` | Per-property candidates for a single module (legacy) |
| `imo_alignment_gaps.csv` | `extract_imo_compendium.py --compare` | Unlinked properties gap report for a single module (legacy) |

The stable committed reference CSV lives at `model/external/imo/imo_compendium_all.csv`.
